# Cost Views Implementation Plan (06c)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add the three remaining cost dashboards, and release them as 0.7.0 of `terraform-aws-jaws-monitoring`:
- **Cost · Project:** one project's spend against its budget;
- **Cost · Databricks:** spend and DBUs at list price, and the all-in cost;
- **Cost · Tasks:** one row per task run, and campaigns.

**Architecture:**
- **One panel builder for every cost dashboard.** The Overview's builders move to `cost-panels.tf`. Each dashboard file then holds only its variables, its panel specs and its rows.
- **Filters say "All" without listing values.** Every multi-value variable gets `allValue = '__all'`, and every query guards it with `('__all' IN ($v) OR <column> IN ($v))`. An empty variable can then never produce `IN ()`, which closes 06b's minor M2.
- **The new numbers are views** in the `cost` schema, like 06b's: `cost.runs`, `cost.campaigns`, `cost.databricks_daily` and `cost.databricks_all_in`. Parts that depend on configuration (the run join tags, the workspace tag) are generated by `cost-sync` from `config.json`.
- **Tag keys are read in all three FOCUS forms.** `cost.tag(tags, key)` reads `Key`, `user:Key` or `user_key`, the normalizer's order. AWS doesn't document which form FOCUS writes. A run's cost rows match its join tags in any form, which fixes 06a's plain-key-only join.

**Tech Stack:** Postgres 17.12 SQL, the 06a/06b `cost-sync` and its Postgres test, Terraform `terraform test`, and the Grafana 13.3.1 smoke test.

**`cost.runs` columns**
- **Identity:**
  - `run_key`;
  - `source` (`record` or `tags`);
  - `project`, `campaign`, `workflow` (the record's `kind`, else the `Workflow` tag), `profile` (`attributes.profile`, else the `Profile` tag), `lifecycle` (`attributes.lifecycle`, else the `Lifecycle` tag);
  - `task` (the `TaskId` tag), `run_id` (the `RunId` tag).
- **Instance:** `instance_type`, `accelerators`, `market`, `zone`, `instance_id` (records only).
- **Time:**
  - `started_at`, `ended_at` (record times; for tag-only runs, the first `charge_period_start` and the last `charge_period_end`);
  - `running` (a record with no `finished` or `swept` event);
  - `hours`: from start to end, or to `cost.now()` while running. For tag-only runs it is the sum of `consumed_quantity` where `lower(consumed_unit)` is `hrs`, `hours` or `hour`.
  - `outcome`: the record's, `swept`, or `running`; null for tag-only runs.
- **Money:**
  - `billed_cost`;
  - `estimated`: the record has an `hourly_usd`, and the run is running, has no cost rows, or ended on a day that isn't complete yet;
  - `cost`: `hours × hourly_usd` when estimated, else `billed_cost`;
  - `hourly_usd`, `on_demand_hourly_usd`, `ceiling_usd`, `max_hours`;
  - `on_demand_cost` (`hours × on_demand_hourly_usd`), `ceiling_percent` (`100 × cost / ceiling_usd`);
  - `gpu_hours` (`hours × accelerators`), `cost_per_gpu_hour` (`cost / nullif(gpu_hours, 0)`).
- **Links:** `run_url`, `pr_url`, `commit_url` (`links.run`, `links.pr`, `links.commit`), `pr` (`#` plus the last path segment of `pr_url`), `commit` (the first 7 characters of `commit_url`'s last segment).

A tag-only run has every join tag on its cost rows and no record with its `run_key`. Its `run_key` is built like the normalizer's, `RunId=<v>;TaskId=<v>` for the configured join tags. Its rows are found through the GIN index (`tags ?| array[...]` over the three forms).

**`cost.campaigns` columns:** `campaign`, `project`, `first_run`, `last_run` (start times), `runs`, `passed`, `failed`, `interrupted`, `instance_hours`, `gpu_hours`, `cost`, `on_demand_cost`, `saved`, `saved_percent` (`saved` ÷ `on_demand_cost`, over runs with an on-demand price), and `cost_per_passed_run` (null with no passed run).

**Inputs**
- **`cost` gains** `databricks_workspace_tag = optional(string, "Workspace")`.
  - Valid: `^[A-Za-z0-9 _.:/=+@-]{1,128}$`.
  - It travels in `config.json` as `databricks_workspace_tag`, and to the Grafana module's `cost` object, which defaults it the same way.
